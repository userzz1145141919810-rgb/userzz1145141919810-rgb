# Yukikaze

折腾 AI、代码和各种奇怪实验的开发者喵。

主要在做大语言模型和表示学习，对几何方法在机器学习里的应用比较感兴趣。平时会写一些解决具体问题的小工具，基本都是单文件、打开就能用的那种。

## 项目

### [web-3d-viewer](https://github.com/userzz1145141919810-rgb/web-3d-viewer)

浏览器里直接预览 OBJ 模型的单文件查看器，支持 MTL 材质与 TGA / DDS 贴图。无需安装，[在线试用](https://userzz1145141919810-rgb.github.io/web-3d-viewer/) 或下载 `index.html` 本地打开。

### [claude-anthropic-clash-rules](https://github.com/userzz1145141919810-rgb/claude-anthropic-clash-rules)

Claude / Anthropic 的 Clash 规则集，按域名、ASN、IP 段三层覆盖，可直接作为 rule-provider 引用。

### [gpt-image-2-5-prompting-guide](https://github.com/userzz1145141919810-rgb/gpt-image-2-5-prompting-guide)

GPT Image 2.5 的提示词手册：角色一致性、姿态迁移、背景替换与多轮编辑，中英双语。

### [silent-identity-layer](https://github.com/userzz1145141919810-rgb/silent-identity-layer)

一个「训练指标全绿、几何层实际退化成恒等映射」的案例复盘，附只用标准库就能跑的复现脚本。
